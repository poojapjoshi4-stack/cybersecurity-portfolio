# Internal Security Audit – Botium Toys

## Project Overview
Conducted an internal security audit for Botium Toys using the NIST Cybersecurity Framework (NIST CSF).

## Audit Scope
- Physical office
- Storefront
- Warehouse
- Online infrastructure
- Customer payment systems

## Risk Assessment
- Data breaches
- Malware attacks
- Unauthorized access
- Loss of customer information

## Compliance Assessment
- PCI DSS
- GDPR

## Recommendations
1. Implement Multi-Factor Authentication (MFA)
2. Encrypt sensitive data
3. Improve employee security training
4. Develop an incident response plan
5. Strengthen monitoring and logging

## Skills Demonstrated
- Security Auditing
- Risk Assessment
- Compliance Analysis
- NIST Cybersecurity Framework
